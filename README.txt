VANI BIRTHDAY WEBSITE
======================

Open index.html in a browser.

ADDING YOUR PHOTOS
------------------
The current version uses visual placeholders so you can decide which photos belong where.
The easiest way to customize it is to replace each placeholder <div class="photo">...</div> in index.html
with an image tag, for example:

<img class="photo" src="photos/photo1.jpg" alt="Our memory">

If you want to use local images, create a "photos" folder next to index.html and put your images there.

IMPORTANT
---------
The ~1,500 km figure is an approximate straight-line distance between the two PIN-code areas,
not an exact home-to-home distance.

The site is intentionally self-contained and uses no external libraries.
